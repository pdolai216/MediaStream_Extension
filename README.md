# MediaStream - Ultimate Media Extractor 🔮

MediaStream is a powerful and modern Google Chrome Extension that instantly extracts all videos, audio tracks, high-resolution images, and iFrame embed links from any webpage. It is an essential tool for web developers, content creators, and media analysts.

---

## 🚀 Key Features

- **Deep Scan Engine:** Scrapes the webpage DOM structure with a single click to extract all media resources.
- **Smart Filtering:** Categorized tab filtering (Video, Audio, Image, iFrame) for easy navigation.
- **Live Search:** Filter through extracted links in real-time by keyword or file extension.
- **Bulk Actions:** Copy all filtered links to your clipboard instantly with a single button.
- **Dark/Light Theme:** A sleek, modern UI that seamlessly supports both dark and light modes.
- **YouTube Support:** Automatically detects and extracts high-quality thumbnail images from YouTube pages or embedded players.
